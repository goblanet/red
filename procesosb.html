Borrar archivos temporales

Presiona las teclas Windows + R para abrir la ventana Ejecutar, ahora escribe %tmp% y presiona Enter.
Se despliega una ventana con varios archivos
Presiona las teclas ctrl + e, para seleccionar todo
Presiona la tecla suprimir
En la  ventana pequeña selecciona la casilla.
Luego presiona o haz clic en omitir , si vuelve aparecer repites lo mismo.
Ahora para terminar vacía la  papelera de reciclaje.

WPS office

Este conjunto de programas se instala de forma automática o lo instalas sin que te des cuenta.
Generalmente son alternativa para Word, Excel, PowerPoint y pdf.
Para la mayoría de las personas que solo maneja los programas de Microsoft, esto es muy molestoso.
 

Otra ventana de Word

Por ejemplo, cuando haces doble clic sobre uno de tus archivos de Word, Se abre con este programa y las herramientas son distintas, por lo tanto vamos a solucionar este inconveniente.

Programa de apertura

Haz clic derecho sobre cualquier archivo de Word
Ubica el texto "Se abre  con".
A su derecha esta WPS office
Mas a la derecha está la opción cambiar
Presiona en este botón y elige Microsoft Word
Luego hacer clic en aceptar,  aplicar y en aceptar. 

Buscar archivos

Abrir una carpeta cualquiera

En su ventana hay diferentes archivos y carpetas
Haz clic en la barra de búsqueda situada en la esquina superior derecha.
Escribe *.mp4
Luego presiona la tecla Enter
Con este comando se busca todos los archivos que tengan la extensión mp4
Nota. - si quieres buscar archivos:
De imagen escribe: *.jpg ; *.png ;  *.webp ;  *.jfif
De Photoshop escribe: *.psd ; de Word escribe: *.doc ; de Excel escribe: *.xls ; de PowerPoint escribe: *.jpg ;  de Access escribe: *.mdb; de Paint escribe: *.bmp
De Audio escribe: *.mp3
